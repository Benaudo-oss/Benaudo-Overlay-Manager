# Politique de sécurité

## Signaler une vulnérabilité

N'ouvrez pas d'issue publique pour une vulnérabilité exploitable. Utilisez la fonction **Security advisories / Report a vulnerability** du dépôt GitHub.

Indiquez si possible :

- la version concernée ;
- les étapes de reproduction ;
- l'impact estimé ;
- toute piste de correction connue.

Les rapports de bonne foi seront étudiés avant toute publication publique.

## Versions prises en charge

Tant que le projet est en version `0.x`, seule la dernière version publiée est prise en charge.

## Authenticité des versions

Les installateurs officiels sont exclusivement ceux joints aux [Releases GitHub](https://github.com/Benaudo-oss/Benaudo-Overlay-Manager/releases). Les fichiers publiés sont générés par GitHub Actions et accompagnés de sommes SHA-256.
