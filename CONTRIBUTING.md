# Contribuer

## Principes

- préserver en priorité les performances d'iRacing ;
- ne pas ajouter de collecte de télémétrie ni de service cloud sans décision explicite ;
- garder l'interface et les textes utilisateur en français ;
- accompagner les changements de comportement par des tests.

## Flux de travail

1. Créer une branche depuis `main`.
2. Effectuer un changement ciblé.
3. Vérifier la compilation Release et les tests.
4. Ouvrir une pull request en complétant le modèle.

Les commits utilisent de préférence une formulation courte, par exemple `feat: ajoute le mode édition` ou `fix: corrige la position sauvegardée`.
